# Clinicians Who Code: The Opinionated Handbook

A practical, opinionated guide for clinicians who want to build healthcare software safely, openly, and quickly.

Written in the first person, by a clinician-developer, for clinician-developers. Strong opinions held lightly. Not a textbook.

## Read the handbook

**<https://pacharanero.github.io/clinicians-who-code-the-opinionated-handbook/>**

## Contribute

This handbook is open source. Typo fixes, broken links, disagreements, and new chapters are all welcome. See the [Contribute](https://pacharanero.github.io/clinicians-who-code-the-opinionated-handbook/contribute/) page or open an [issue](https://github.com/pacharanero/clinicians-who-code-the-opinionated-handbook/issues).

## Build locally

```bash
pip install -r requirements.txt
zensical serve
```

The site is built with [Zensical](https://zensical.org/) and deployed to GitHub Pages via GitHub Actions on every push to `alpha`.
